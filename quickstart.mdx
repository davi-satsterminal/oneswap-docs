This walks you through one complete escrow swap: create it, hand your user a deposit party, and wait for the output to be returned to them.

<Note>
  Escrow settlement is processed by a background monitor that is enabled per-deployment.
  Escrow swaps are live on OneSwap **devnet** today; **mainnet** access is enabled per
  integrator — reach out to get provisioned. Against a deployment without the monitor, a swap
  stays in `awaiting_deposit` / `deposit_detected` and never settles.
</Note>

<Steps>
  <Step title="Install the SDK">
    ```bash
    npm install @oneswap/sdk
    ```
  </Step>

  <Step title="Create an API key">
    Create an SDK key from your OneSwap account (self-serve). The key looks like
    `sk_live_` followed by 48 hex characters and is shown **once** at creation — store it
    somewhere safe. See [API keys](/guides/api-keys) for the full flow.

    Keep the key on your **server only**. It is your integrator credential; never ship it to a
    browser or to an end-user.
  </Step>

  <Step title="Initialize the client">
    ```typescript
    import { OneSwap } from '@oneswap/sdk'

    const oneswap = new OneSwap({ apiKey: 'sk_live_...' })
    ```

    The client sends your key on every escrow request as the `x-sdk-key` header. It talks to
    **mainnet** by default; pass `environment: 'devnet'` to use the devnet backend — the SDK
    resolves the URL itself, so you never set one:

    ```typescript
    const oneswap = new OneSwap({
      apiKey: 'sk_live_...',
      environment: 'devnet', // 'mainnet' (default) | 'devnet'
    })
    ```
  </Step>

  <Step title="Create the escrow swap">
    ```typescript
    const swap = await oneswap.escrow.createSwap({
      userRef: 'user-1042', // your stable id for this end-user
      inSymbol: 'CBTC',      // token the user deposits
      amountIn: 0.01,        // amount of inSymbol to swap
      outSymbol: 'HTEST',    // token to return to the user
    })

    console.log(swap.id)           // 'esc_...'
    console.log(swap.status)       // 'awaiting_deposit'
    console.log(swap.depositParty) // the Canton party the user must fund
    console.log(swap.deadline)     // ISO timestamp — deposit before this
    ```

    Only one open swap is allowed per `userRef` at a time.
  </Step>

  <Step title="Show the user the deposit party">
    Tell your end-user to send **`amountIn` of `inSymbol`** (here, `0.01 CBTC`) to
    `swap.depositParty` before `swap.deadline` (60 minutes from creation).

    The deposit must land within **1%** of `amountIn`, or it is refunded. OneSwap never guesses
    intent from a wrong amount.
  </Step>

  <Step title="Wait for completion">
    ```typescript
    const done = await oneswap.escrow.waitForSwap(swap.id)

    if (done.status === 'returned') {
      // Success — output was paid back to the party that funded the swap
      console.log(`Returned ${done.amountOut} ${done.outSymbol} to ${done.senderParty}`)
    } else {
      // refunded | expired | failed
      console.log(`Swap ended as ${done.status}`, done.error)
    }
    ```

    `waitForSwap` resolves once the swap reaches a terminal status
    (`returned`, `refunded`, `expired`, or `failed`), or when its local timeout is hit.
  </Step>
</Steps>

## Complete example

<CodeGroup>
```typescript TypeScript
import { OneSwap } from '@oneswap/sdk'

const oneswap = new OneSwap({ apiKey: 'sk_live_...' })

async function swapForUser() {
  // 1. Create the escrow swap
  const swap = await oneswap.escrow.createSwap({
    userRef: 'user-1042',
    inSymbol: 'CBTC',
    amountIn: 0.01,
    outSymbol: 'HTEST',
  })

  // 2. Show your end-user where to send the deposit
  console.log(`Send ${swap.amountIn} ${swap.inSymbol} to ${swap.depositParty}`)
  console.log(`Deposit before ${swap.deadline}`)

  // 3. Wait for OneSwap to detect, swap, and return the output
  const done = await oneswap.escrow.waitForSwap(swap.id)

  if (done.status === 'returned') {
    console.log(`Done — returned ${done.amountOut} ${done.outSymbol} to ${done.senderParty}`)
  } else {
    console.log(`Swap ended as ${done.status}`, done.error)
  }
}

swapForUser()
```

```bash curl
# 1. Create the escrow swap
curl -X POST https://api.oneswap.cc/swapv2/api/sdk/escrow/swap \
  -H "x-sdk-key: sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "userRef": "user-1042",
    "inSymbol": "CBTC",
    "amountIn": 0.01,
    "outSymbol": "HTEST"
  }'
# → { "id": "esc_...", "status": "awaiting_deposit", "depositParty": "...", "deadline": "..." }

# 2. Poll the swap until it reaches a terminal status
curl https://api.oneswap.cc/swapv2/api/sdk/escrow/swap/esc_... \
  -H "x-sdk-key: sk_live_..."
# → { "id": "esc_...", "status": "returned", "amountOut": 0.98, "senderParty": "...", ... }
```
