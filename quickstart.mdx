## Install

```bash
npm install oneswap-v2-sdk
```

Self-contained: uses global `fetch` (Node 18+ or any modern browser). Point it at
a OneSwap v2 deployment:

```ts
import { OneSwapV2 } from 'oneswap-v2-sdk';
const dex = new OneSwapV2('https://api.oneswap.cc/swapv2');
```

## Custodial: swap in 4 lines

The platform provisions a wallet for your user and signs on their behalf.

```ts
await dex.register('alice', 'a-strong-password');   // or dex.login(...)
console.log('deposit to:', await dex.depositAddress());
await dex.deposit.acceptAll();                       // accept incoming CIP-56 tokens

const q = await dex.quote(1.0, true);                // xToY = assetX → assetY
const res = await dex.swap(1.0, true, { slippageBps: 100 });
console.log('atomic:', res.atomic, 'tx:', res.updateId, 'out:', res.amountOut);
```

<Note>
`res.atomic` is always `true` — v2 only settles atomic DvP. `res.updateId` is the
Canton transaction id you can look up on a scan explorer.
</Note>

## Interactive: swap from a self-custody wallet on any validator

Your user keeps their own key. Implement a `WalletSigner` over their wallet, and
OneSwap builds the atomic DvP for them to sign.

```ts
import { OneSwapV2, WalletSigner } from 'oneswap-v2-sdk';
const dex = new OneSwapV2('https://api.oneswap.cc/swapv2');

const wallet: WalletSigner = {
  party: 'alice::1220ab…',                        // user party on ANY validator
  publicKeyFingerprint: '1220ef…',
  signHash: (hash) => myWallet.signEd25519(hash), // base64/hex Ed25519 signature
};

const res = await dex.interactive.swap({
  partyA: wallet.party,
  partyB: operatorParty,
  legs: [{ sender: wallet.party, receiver: poolParty, instrumentId: { admin, id: 'cETH' }, amount: '1.0' }],
  signer: wallet,
});
console.log('settled:', res.updateId);
```

The user's key never leaves their side, and the swap settles all-or-nothing.

## Provide liquidity

```ts
await dex.addLiquidity(1.0, 1000);                  // amounts of assetX / assetY
console.log(await dex.positions());                 // [{ lpTokens, sharePct, valueX, valueY }]
const pos = (await dex.positions())[0];
await dex.removeLiquidity(pos.lpTokens);
```

## Persist a session

```ts
const token = dex.session;                          // store it
const dex2 = new OneSwapV2(url, { session: token });
await dex2.refreshAccount();
```
