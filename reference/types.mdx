## Client options

Options passed to the `OneSwap` constructor.

```typescript
interface OneSwapOptions {
  apiKey: string                          // 'sk_live_...' — sent as the x-sdk-key header
  environment?: 'mainnet' | 'devnet'      // default 'mainnet'; the SDK resolves the URL itself
  timeout?: number                        // per-request timeout in ms (default 30000)
}
```

## `createSwap` args

The argument to `oneswap.escrow.createSwap`.

```typescript
interface CreateEscrowSwapArgs {
  userRef: string      // your stable id for the end-user (one open swap per userRef at a time)
  inSymbol: string     // token the user deposits, e.g. 'CBTC'
  amountIn: number     // decimal amount of inSymbol to swap
  outSymbol: string    // token to return to the user, e.g. 'HTEST'
  minOut?: number      // optional hard floor on output; below it the swap is refunded
  slippageBps?: number // optional; default 200 (2%)
}
```

## `waitForSwap` options

The optional second argument to `oneswap.escrow.waitForSwap`.

```typescript
interface WaitForSwapOptions {
  pollMs?: number    // default 3000
  timeoutMs?: number // default 900000 (15 min)
}
```

## `EscrowStatus`

The lifecycle status of a swap. Terminal statuses are `returned`, `refunded`, `expired`, and `failed`.

```typescript
type EscrowStatus =
  | 'awaiting_deposit'
  | 'deposit_detected'
  | 'swapping'
  | 'returned'
  | 'refunded'
  | 'expired'
  | 'failed'
```

## `EscrowSwap`

Returned by `createSwap`, `getSwap`, and `waitForSwap`.

```typescript
interface EscrowSwap {
  id: string                    // 'esc_...'
  status: EscrowStatus
  poolId: string
  inSymbol: string
  outSymbol: string
  amountIn: number
  minOut: number | null
  depositParty: string          // the Canton party id the end-user must fund
  deadline: string              // ISO timestamp; deposit must arrive before this
  amountOut?: number | null     // set once returned
  senderParty?: string | null   // the party that funded (output is returned here)
  error?: string | null
}
```

| Field | Notes |
|---|---|
| `id` | Swap id, `esc_...`. Store it against your `userRef`. |
| `status` | See [`EscrowStatus`](#escrowstatus) and the [status reference](/guides/escrow-swaps#status-reference). |
| `poolId` | The pool the `{ inSymbol, outSymbol }` pair resolved to. |
| `amountIn` | The amount the user must deposit — within **1%** tolerance. |
| `minOut` | The hard output floor, or `null` if none was set. |
| `depositParty` | The Canton party id the end-user sends `amountIn` of `inSymbol` to. |
| `deadline` | ISO timestamp, 60 minutes from creation. Deposit before this or the swap expires. |
| `amountOut` | The returned amount of `outSymbol`; set once `status` is `returned`. |
| `senderParty` | The party that funded the deposit; the output is returned here. |
| `error` | Set when `status` is `failed`. |
