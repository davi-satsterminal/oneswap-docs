The client exposes four namespaces: `swaps` (execution), `quotes`, `pools`, and `tokens` (market data).

## Constructor

```typescript
import { OneSwap } from '@oneswap/sdk'

const oneswap = new OneSwap({ apiKey: 'sk_live_...' })
```

<ParamField path="apiKey" type="string" required>
  Your integrator API key (`sk_live_` followed by 48 hex chars). Sent on every request as
  the `x-sdk-key` header. Keep it server-side only.
</ParamField>

<ParamField path="environment" type="'mainnet' | 'devnet'" default="mainnet">
  Which OneSwap backend to use. The SDK resolves the URL itself — you never pass a raw URL.
</ParamField>

<ParamField path="timeout" type="number" default="30000">
  Per-request timeout in milliseconds.
</ParamField>

```typescript
// Point at devnet for integration testing
const oneswap = new OneSwap({
  apiKey: 'sk_live_...',
  environment: 'devnet',
})
```

## `swaps.createSwap`

Create a swap. Returns a [`Swap`](/reference/types#swap) in status `awaiting_deposit`, carrying the `depositParty` your end-user must fund and the `deadline` they must beat.

```typescript
oneswap.swaps.createSwap(args: {
  userRef: string
  inSymbol: string
  amountIn: number
  outSymbol: string
  minOut?: number
  slippageBps?: number
}): Promise<Swap>
```

<ParamField path="userRef" type="string" required>
  Your stable id for the end-user. Only one open swap per `userRef` at a time.
</ParamField>

<ParamField path="inSymbol" type="string" required>
  The token the user deposits, e.g. `'CBTC'`.
</ParamField>

<ParamField path="amountIn" type="number" required>
  Decimal amount of `inSymbol` to swap. The deposit must arrive within **1%** of this amount.
</ParamField>

<ParamField path="outSymbol" type="string" required>
  The token to return to the user, e.g. `'HTEST'`.
</ParamField>

<ParamField path="minOut" type="number">
  Optional hard floor on the output amount. If the swap would return less than this, it is refunded.
</ParamField>

<ParamField path="slippageBps" type="number" default="200">
  Optional slippage tolerance in basis points. Defaults to `200` (2%).
</ParamField>

```typescript
const swap = await oneswap.swaps.createSwap({
  userRef: 'user-1042',
  inSymbol: 'CBTC',
  amountIn: 0.01,
  outSymbol: 'HTEST',
  minOut: 0.95,
  slippageBps: 100,
})

console.log(swap.id)           // 'esc_...'
console.log(swap.status)       // 'awaiting_deposit'
console.log(swap.depositParty) // the party the user must fund
console.log(swap.deadline)     // ISO timestamp
```

Throws if `{ inSymbol, outSymbol }` has no visible pool (`no pool for IN/OUT`) or `OpenSwapExistsError` if the `userRef` already has an open swap. See [Error handling](/guides/error-handling).

<Note>
  `oneswap.escrow` — the 1.0.0 name for this namespace — still works as a deprecated alias of
  the same instance.
</Note>

## `swaps.getSwap`

Fetch the current state of a swap by id. Only returns swaps owned by your integrator.

```typescript
oneswap.swaps.getSwap(id: string): Promise<Swap>
```

<ParamField path="id" type="string" required>
  The swap id returned by `createSwap` (`esc_...`).
</ParamField>

```typescript
const swap = await oneswap.swaps.getSwap('esc_...')
console.log(swap.status)
```

## `swaps.waitForSwap`

Poll a swap until it reaches a terminal status (`returned`, `refunded`, `expired`, `failed`, or `cancelled`), or until the local timeout. Resolves with the final [`Swap`](/reference/types#swap).

```typescript
oneswap.swaps.waitForSwap(id: string, opts?: {
  pollMs?: number
  timeoutMs?: number
}): Promise<Swap>
```

<ParamField path="id" type="string" required>
  The swap id to wait on.
</ParamField>

<ParamField path="opts.pollMs" type="number" default="3000">
  Poll interval in milliseconds.
</ParamField>

<ParamField path="opts.timeoutMs" type="number" default="900000">
  Give up after this many milliseconds (default 15 minutes). On timeout the swap may still be
  settling — resume with `getSwap(id)`.
</ParamField>

```typescript
const done = await oneswap.swaps.waitForSwap('esc_...', {
  pollMs: 3000,
  timeoutMs: 900000,
})

if (done.status === 'returned') {
  console.log(`Returned ${done.amountOut} ${done.outSymbol} to ${done.senderParty}`)
}
```

## `swaps.getOpenSwap`

<Info>Added in SDK 1.2.0.</Info>

Fetch the user's open (non-terminal) swap, or `null` if they have none.

A `userRef` may hold only one open swap at a time — `createSwap` throws [`OpenSwapExistsError`](/guides/error-handling) while one is live. Use this to recover the swap id when you no longer have it: after a process restart, or when the `createSwap` response was lost in flight.

```typescript
oneswap.swaps.getOpenSwap(userRef: string): Promise<Swap | null>
```

<ParamField path="userRef" type="string" required>
  Your stable identifier for the end user, the same value passed to `createSwap`.
</ParamField>

```typescript
const open = await oneswap.swaps.getOpenSwap('user-123')

if (open) {
  console.log(`${open.id} is ${open.status}`)
}
```

## `swaps.cancel`

<Info>Added in SDK 1.2.0.</Info>

Cancel a swap that has not yet received a deposit, freeing the user to start another immediately instead of waiting out the one-hour deposit deadline. Resolves with the closed [`Swap`](/reference/types#swap) (`status: 'cancelled'`).

Only a swap still in `awaiting_deposit` can be cancelled. Once a deposit has arrived the swap holds funds and must run to completion — cancelling then throws `ConflictError` (409), and you should `waitForSwap` instead. Calling this on an already-finished swap returns it unchanged, so it is safe to retry.

```typescript
oneswap.swaps.cancel(id: string): Promise<Swap>
```

<ParamField path="id" type="string" required>
  The swap id to cancel (`esc_...`).
</ParamField>

Together with `getOpenSwap`, this is how you recover from a blocked user:

```typescript
import { OpenSwapExistsError } from '@oneswap/sdk'

try {
  swap = await oneswap.swaps.createSwap({
    userRef: 'user-123',
    inSymbol: 'CC',
    amountIn: 100,
    outSymbol: 'CBTC',
  })
} catch (err) {
  if (!(err instanceof OpenSwapExistsError)) throw err

  const open = await oneswap.swaps.getOpenSwap('user-123')

  if (open?.status === 'awaiting_deposit') {
    await oneswap.swaps.cancel(open.id) // nothing was deposited — release and retry
  } else if (open) {
    await oneswap.swaps.waitForSwap(open.id) // funds are in flight — let it finish
  }
}
```

## `quotes.get`

Quote a swap of `amount` `from`-tokens into `to`-tokens. The SDK resolves the pool that trades the pair (or takes `poolId` verbatim), derives the direction, and returns a [`QuoteResult`](/reference/types#quoteresult) — the quote plus the resolved `poolId` and `xToY`.

```typescript
oneswap.quotes.get(args: {
  from: string
  to: string
  amount: number
  poolId?: string
  walletId?: string
}): Promise<QuoteResult>
```

<ParamField path="from" type="string" required>
  Symbol of the token you pay with, e.g. `'CC'`.
</ParamField>

<ParamField path="to" type="string" required>
  Symbol of the token you receive, e.g. `'CBTC'`.
</ParamField>

<ParamField path="amount" type="number" required>
  Amount of `from` to swap. Must be positive.
</ParamField>

<ParamField path="poolId" type="string">
  Pin a specific pool instead of resolving one from the symbol pair. The pool must still trade
  exactly `from`/`to`.
</ParamField>

<ParamField path="walletId" type="string">
  A custodial wallet id you own — the quote then reports `walletBalanceIn` and
  `sufficientBalance` for that wallet. Requires an authenticated session context, so most SDK
  callers omit it.
</ParamField>

```typescript
const quote = await oneswap.quotes.get({ from: 'CC', to: 'CBTC', amount: 100 })

console.log(quote.amountOut)      // expected output in CBTC
console.log(quote.priceImpactPct) // price impact of this trade size
console.log(quote.effFeeBps)      // effective pool fee after any discount
console.log(quote.networkFeeIn)   // network fee carved from the input
console.log(quote.poolId)         // the pool the pair resolved to
console.log(quote.xToY)           // direction within that pool
```

Throws [`NoDirectPoolError`](/guides/error-handling#the-no-direct-pool-case) when no pool trades the pair (there is no multi-hop routing) and `AmbiguousPoolPairError` (with `candidates`) when several do — retry with `poolId`. The pool list backing symbol resolution is cached for 30 seconds per client instance.

<Note>
  `networkFeeIn` can be `0` on a quote — the network fee is not always taken from the input at
  quote time. Deposit swaps (`swaps.createSwap`) DO settle the per-swap network fee from the
  input token (see [the Swaps guide](/guides/swaps#network-fee-comes-from-the-input)), so the
  settled output can come in slightly below a quote whose `networkFeeIn` was `0`. Set `minOut`
  with that headroom in mind.
</Note>

## `pools.list`

All pools visible to the caller, with live reserves and fee configuration.

```typescript
oneswap.pools.list(): Promise<Pool[]>
```

```typescript
const pools = await oneswap.pools.list()
for (const p of pools) {
  console.log(`${p.id}: ${p.assetX.symbol}/${p.assetY.symbol}`, p.reserveX, p.reserveY)
}
```

## `pools.get`

One pool plus its full settled-swap history.

```typescript
oneswap.pools.get(poolId: string): Promise<PoolDetail>  // { pool, swaps }
```

<ParamField path="poolId" type="string" required>
  The pool id (`rt-...`), from `pools.list()` or a quote's `poolId`.
</ParamField>

```typescript
const { pool, swaps } = await oneswap.pools.get('rt-...')
console.log(pool.feeBps, swaps.length)
```

## `pools.getTicker`

Live market data for a pool: USD price derived from the pool's own reserve ratio, 24h change, and 24h volume. Returns a [`PoolTicker`](/reference/types#poolticker). Cached up to 30s server-side.

```typescript
oneswap.pools.getTicker(poolId: string): Promise<PoolTicker>
```

<ParamField path="poolId" type="string" required>
  The pool id (`rt-...`).
</ParamField>

```typescript
const ticker = await oneswap.pools.getTicker('rt-...')

console.log(ticker.pair)                 // 'CC/CBTC'
console.log(ticker.base)                 // the asset being priced, e.g. 'CBTC'
console.log(ticker.price.usd)            // e.g. '61462.225'
console.log(ticker.priceChange24h.pct)   // e.g. '1.8342' — or null during warm-up
console.log(ticker.volume24h.usd)        // 24h volume in USD
console.log(ticker.volume24h.swaps)      // number of swaps in the window
```

`priceChange24h` fields are `null` until the pool's price history is at least 24h old, and `price.usd` is `null` for pools that cannot be USD-priced (e.g. unseeded pools).

## `tokens.list`

The tokens OneSwap can settle — display symbol plus the on-ledger instrument identity.

```typescript
oneswap.tokens.list(): Promise<Token[]>
```

```typescript
const tokens = await oneswap.tokens.list()
console.log(tokens.map((t) => t.symbol)) // ['CC', 'CBTC', ...]
```
