```ts
import { OneSwapV2 } from 'oneswap-v2-sdk';
const dex = new OneSwapV2(baseUrl, { session?, adminToken?, slippageBps? });
```

## Session (custodial)

| method | returns | description |
|---|---|---|
| `register(user, pass)` | `Account` | create an account + platform wallet; sets session |
| `login(user, pass)` | `Account` | sign in; sets session + wallet |
| `setSession(token)` | `this` | restore a persisted session token |
| `session` | `string \| null` | current session token |
| `me` | `Account \| null` | current account |
| `walletId` | `string` | current wallet id (throws if not logged in) |
| `refreshAccount()` | `Account` | repopulate account from the server |
| `logout()` | `void` | clear session |

## Market (public)

| method | returns | description |
|---|---|---|
| `tokens()` | `Token[]` | listed tokens |
| `config()` | `{ defaultPoolId, tokens }` | app config + default pool |
| `pools()` | `Pool[]` | all visible pools |
| `pool(poolId?)` | `Pool` | one pool (default if omitted) |
| `poolId()` | `string` | the canonical/default pool id (cached) |
| `quote(amountIn, xToY, poolId?)` | `Quote` | price a swap |
| `rate()` | `{ rate, usdPerMb }` | live CC price / network-fee context |

## Custodial wallet

| method | returns | description |
|---|---|---|
| `balances()` | `Balance[]` | token balances |
| `balance(symbol)` | `number` | one token balance |
| `depositAddress()` | `string` | wallet party id — send tokens here |
| `positions()` | `Position[]` | LP positions |
| `deposit.offers()` | `Offer[]` | pending incoming deposits |
| `deposit.acceptAll()` | `{ accepted }` | accept all deposits |
| `deposit.accept(cid)` / `deposit.reject(cid)` | — | accept/reject one |
| `traffic()` | `{ enabled, balance, ledger }` | prepaid CC traffic |
| `topupTraffic(cc)` | `{ balance }` | add traffic credit |
| `withdraw(symbol, amount, toParty)` | `{ … }` | send tokens to any party |

## Trade + liquidity (custodial)

| method | returns | description |
|---|---|---|
| `swap(amountIn, xToY, opts?)` | `SwapResult` | **atomic-DvP** swap |
| `addLiquidity(x, y, opts?)` | `{ lpTokens, usedX, usedY }` | provide liquidity |
| `removeLiquidity(lpTokens, opts?)` | `{ amountX, amountY }` | withdraw |

`opts`: `{ slippageBps?, poolId?, idempotencyKey? }`.

## Interactive (self-custody, cross-validator)

All under `dex.interactive`:

| method | returns | description |
|---|---|---|
| `createMandate(partyA, partyB, opts?)` | `{ mandateId }` | open a settlement mandate |
| `quote(parties, mandateId, legs, issuerCount?)` | `Quote` | price interactive legs |
| `prepare(parties, mandateId, legs)` | `Prepared` | build the unsigned atomic DvP |
| `execute(prepared, signerOrSig)` | `SwapResult` | submit signature + settle |
| `swap({ partyA, partyB, legs, signer, mandateId?, issuerCount? })` | `SwapResult` | one-shot mandate→prepare→sign→execute |

`execute` accepts either a `WalletSigner` (it calls `signHash` for you) or a
ready-made `Signature`.

See [Types](/reference/types) for `Account`, `Pool`, `Quote`, `SwapResult`,
`WalletSigner`, `Prepared`, `Leg`, and more.
